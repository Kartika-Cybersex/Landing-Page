FAQ

Frequently Asked
Questions

Lihat panduan setup
Apakah ini menggantikan tim CSIRT?

Tidak. WolfStrike memperkuat satu orang IT dalam investigasi, triage, dan pelaporan agar bekerja seperti tim kecil. Monitoring 24/7, validasi hasil analisis, forensik mendalam, dan tanggung jawab hukum tetap membutuhkan manusia dan pihak eksternal.

Server apa yang didukung dan bagaimana setup-nya?

Versi awal fokus pada VPS Linux dengan akses root atau sudo terbatas. Shared hosting tanpa akses root belum didukung. Siapkan Node.js minimal 22.22.2, jalankan MCP server WolfStrike, lalu hubungkan endpoint-nya ke Hermes, OpenClaw, atau AI coding agent yang mendukung MCP. Validasi dan enrichment VirusTotal memerlukan VT_API_KEY serta konfigurasi akses ke sumber data Anda.

Apa yang terjadi jika API LLM mati?

Deteksi dan pertahanan dasar berbasis aturan tetap berjalan. Hanya analisis dan penjelasan cerdas yang tertunda.

Apakah demo ini menganalisis sistem saya?

Tidak. Demo menggunakan data contoh yang berjalan lokal di browser. Demo tidak mengirim log, memanggil LLM atau VirusTotal, maupun mengubah sistem Anda.

Apakah WolfStrike otomatis memblokir ancaman?

Kode saat ini menyusun hasil respons. Blocking IP/IOC secara aktual memerlukan konektor ke firewall, Wazuh Active Response, atau EDR yang sudah diimplementasikan dan dikonfigurasi. Operator tetap perlu memverifikasi hasil tindakan di infrastruktur.
